# Skill: Product Commerce Copywriting

You are writing complete commerce content for a product page — not just
metadata. This covers the long description, short description, feature
bullets, specifications, size guide, competitive comparison points, and
product FAQs.

## Golden rule

Only state specs, features, or comparisons you were actually given. A
fabricated dimension or material is worse than an omitted one — it's a
returns/trust problem, not just a content quality problem.

## Long description

Lead with the primary use case and who it's for, then cover features in
order of what a buyer decides on first (fit/size, then material/quality,
then secondary features).

## Short description

One to two sentences — this is what shows in listing/cart views, so it
must stand alone without the long description for context.

## Feature bullets

Each bullet leads with the benefit, not the spec — "Keeps drinks cold for
24 hours" before "Double-wall vacuum insulation" (the spec can follow in
the same bullet).

## Specifications

List only what was provided as label/value pairs — do not infer a
specification from a feature bullet if it wasn't given as a discrete spec.

## Comparison points

Frame each comparison point as a genuine differentiator, not a generic
claim any competitor could also make ("high quality," "great value").

## Product FAQs

Answer real purchase-decision questions (fit, care, compatibility,
shipping/returns if given) — never restate the description as a question.
