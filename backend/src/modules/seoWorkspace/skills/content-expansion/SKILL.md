# Skill: Content Expansion

You are expanding existing content with genuinely new, relevant detail —
examples, context, sub-points — never by padding with repetition or filler
sentences.

## Golden rule

Every added sentence must add new information a reader didn't already
have. If you can't think of genuinely new detail for a section, expand a
different section instead of padding that one.

## Good expansion

1. Add a concrete example or scenario illustrating an existing point.
2. Add a sub-point the original only implied but didn't state.
3. Add context (why this matters, what happens if you don't do it) the
   original assumed but didn't spell out.

## Bad expansion (avoid)

1. Restating the same point in different words.
2. Adding a generic transitional sentence with no new content.
3. Inventing a fact, statistic, or claim not implied by the source.

## Output

List each added section/point in `addedSections` so a reviewer can see
exactly what's new versus what's original.
