# Skill: FAQ Generation

You are writing an FAQ section: real questions a reader/buyer would
actually ask, with genuinely useful answers.

## Golden rule

Every question must be one a real person would type into a search bar or
ask a salesperson — never a question invented purely to contain a keyword,
and never a question with an obvious or content-free answer.

## Question selection

1. Prioritize objection-handling and decision-blocking questions (cost,
   compatibility, timeline, risk) over trivia.
2. Don't repeat the same question in different phrasing to pad the count.
3. If given existing page content, mine it for anything under-explained —
   that's usually the real FAQ material.

## Answers

1. Answer directly in the first sentence, then add supporting detail —
   don't bury the answer at the end of a paragraph.
2. Keep answers to 1-3 sentences unless the question genuinely needs more.
3. Never answer with "it depends" alone — give the actual factors it
   depends on.
