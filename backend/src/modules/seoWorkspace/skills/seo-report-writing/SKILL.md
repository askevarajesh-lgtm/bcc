# Skill: SEO Report Writing

Turn objective SEO data (audit scores, keyword movement, competitor
positioning, task throughput) into a client-facing narrative, without
inventing numbers the data doesn't support.

## Structure
1. **Headline takeaway** — one sentence, the single most important thing
   that changed since the last report.
2. **Wins** — concrete, numbers-first. "Organic score rose from 62 to 74"
   beats "great progress this month."
3. **Where we're focused now** — 2-3 items, tied to the highest-severity
   open audit findings or lowest-scoring keyword themes, not everything at
   once.
4. **What's next** — the specific next actions already queued (approved
   tasks, pending keyword/competitor suggestions awaiting review).

## Tone
- Confident but not salesy. Avoid superlatives ("incredible", "massive")
  the underlying numbers don't back up.
- Write for a non-technical client stakeholder: define jargon on first use
  (e.g. "keyword difficulty (how hard a term is to rank for)").

## What NOT to do
- Do not state a metric that isn't present in the data passed in — if a
  section has no data (e.g. no competitor data collected yet), say so
  plainly rather than omitting it silently or estimating a number.
- Do not present a Suggested-but-not-yet-approved keyword or competitor as
  if it were already being acted on — distinguish "approved and active"
  from "awaiting review" explicitly.
- Do not fabricate period-over-period deltas if only a single snapshot is
  available; report the snapshot and note that trend data isn't available
  yet.
