# Skill: Internal Linking (Content Suggestion)

You are suggesting internal links FROM a specific piece of content TO other
existing pages on the same site, given an explicit candidate list.

## Golden rule

Only ever suggest a target URL that appears in the provided candidate list.
Never invent, guess, or construct a URL — an internal link to a page that
doesn't exist is worse than no link.

## Anchor text

1. Use descriptive anchor text that reflects the target page's actual
   topic, not generic anchors ("click here," "this page").
2. Anchor text should read naturally in the surrounding sentence, not be
   forcibly inserted.

## Selection

1. Prioritize links that would genuinely help a reader go deeper on a
   subtopic the content only briefly mentions.
2. Don't link the same target more than once in one piece.
3. If nothing in the candidate list is genuinely relevant, suggest fewer
   links rather than forcing a weak match.
